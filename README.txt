CASE ZONE — متجر جرابات موبايل (نموذج أولي)

الملفات:
- index.html: الواجهة الرئيسية والمتجر ونموذج الطلب
- style.css: التصميم المتجاوب للموبايل والكمبيوتر
- products.js: أسماء المنتجات والتصنيفات والأسعار
- script.js: الفلترة واختيار المنتج وتجهيز رسالة الطلب
- config.js: رقم واتساب المتجر واسم المتجر والعملة

قبل النشر:
1. افتح config.js في محرر نصوص.
2. غيّر whatsappNumber إلى رقم واتساب بصيغة دولية بدون + أو مسافات. مثال مصري: 2010XXXXXXX (اكتب الرقم الحقيقي بدل X).
3. عدّل الأسعار والتصميمات في products.js.
4. افتح index.html في المتصفح للتجربة.
5. للنشر برابط عام، ارفع الملفات إلى GitHub Pages أو Netlify.

ملاحظات:
- هذا نموذج واجهة أولي؛ لا يحفظ الطلبات داخل قاعدة بيانات ولا يحتوي على لوحة إدارة فعلية.
- إرسال الطلب يفتح واتساب برسالة جاهزة، والعميل يحتاج الضغط على إرسال داخل واتساب.
- صور المنتجات الحالية مرسومة عبر CSS كعينات تصميم وليست صور جرابات فعلية.
- يتطلب تحميل الخط من Google Fonts اتصالًا بالإنترنت؛ الصفحة نفسها تعمل محليًا.
